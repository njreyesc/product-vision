# staff-engineer-growth

План роста от Senior до **Staff Engineer** через агентные проекты, привязанный к
системе скиллов из репозитория `product-vision` (цепочка
Product Vision → Бизнес-архитектура → ИТ-архитектура → Валидатор, SDD,
трассируемость, gate, роадмап R0–R5).

> Это рабочий карьерный документ, а не публичная статья. Цель — превратить уже
> существующую спеку на систему скиллов в **доказуемый Staff-импакт**.

## Состав

| Файл | Назначение |
|------|------------|
| `README.md` | Этот индекс |
| `growth-plan.md` | Senior→Staff: разница, проекты по агентам, план на 90 дней |

## Главный тезис

Спека на систему скиллов уже мыслит на уровне **системы**, а не отдельного
агента — это правильный Staff-инстинкт. Разрыв сейчас не в идее, а в пути
**«спека → запущено → измеримо → этим пользуются другие»**. Весь план в
`growth-plan.md` закрывает именно этот разрыв.

## Как пользоваться

1. Прочитать `growth-plan.md` целиком один раз.
2. Взять блок «Ближайшие 90 дней» как чеклист.
3. Раз в 2 недели сверяться: появились ли числа (KPI) и внешние пользователи.
