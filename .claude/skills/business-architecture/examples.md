# Пример выхода (Business Architecture)

Эталонный сквозной прогон на продукте «оценка рисков контрагента». Вход — выход примера A из
`product-vision` (внутренний режим): `VIS-001`, цели `GOAL-001` (сократить цикл решения) /
`GOAL-002` (снизить долю повторных ревью), метрики `MET-001`/`MET-002`, принцип `PRIN-001`
(объяснимость обязательна), сегмент `SEG-001` (риск-менеджер). Структуру и поля бери из
[templates.md](templates.md) и [contract.md](contract.md). Прогон проходит self-check из
[SKILL.md](SKILL.md): каждая capability трассируется вверх, требования измеримы, `PRIN-001`
отражён в требовании.
