# Шаблон Capability Impact Map / Карта ФБС проекта

Это **discovery-форма** карты бизнес-возможностей: повествовательный шаблон для проработки
capability до того, как они лягут в табличный `## Capability map` (см. [templates.md](templates.md)).
Здесь добавляются два измерения, которых нет в таблице: **тип impact** (use / improve / create /
integrate / enabler) и **анализ gap** (что уже есть сейчас → что нужно закрыть).

Используй эту форму, когда нужно осмыслить разрыв между as-is и to-be или объяснить, какие
capability создаются с нуля, а какие — переиспользуются/улучшаются. Каждой capability присвой
`id` (`CAP-001`, `CAP-002`, …) — тот же, что и в табличной carte и в `trace_up` для `it-architecture`.

Правила переноса в контракт (см. [contract.md](contract.md)):
- «Связанная цель Vision» → поле `trace_up` (`GOAL-*` / `MET-*` / `PRIN-*` / `SEG-*`).
- «Impact» → поле `impact` (use / improve / create / integrate / enabler).
- «Gap / что нужно закрыть» → поле `gap`; «Что уже есть сейчас» фиксируется в `source` как as-is.
- Выбирай **5–9 ключевых** capability — не дроби на мелкие задачи и не описывай системы.

## 4. Самопроверка

- [ ] Для каждой цели Vision есть хотя бы одна связанная capability.
- [ ] Выбрано 5–9 ключевых capabilities.
- [ ] Capabilities описаны как способности бизнеса, а не как системы, технологии или задачи проекта.
- [ ] Для каждой capability понятно, что должна уметь организация.
- [ ] Для каждой capability указан impact type (use / improve / create / integrate / enabler).
- [ ] Для каждой capability указано, что уже есть сейчас и какой gap нужно закрыть.
- [ ] Каждой capability присвоен `id` (`CAP-00X`) для переноса в табличную Capability map и `trace_up`.
