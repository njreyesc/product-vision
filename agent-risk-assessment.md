# Агент оценки рисков

## Карточка (компактно, 4 предложения)

**Чем уникален:**
Автоматически выявляет и классифицирует риски по сделке и клиенту в разрезе типов —
репутационный, правовой, акционерный, недостаточность обеспечения, приостановление деятельности,
риск диверсификации/концентрации и др. Для каждого риска даёт уровень, обоснование и ссылку на
источник — как прозрачный второй взгляд, а не непрозрачный автопилот.

**Вход:**
Идентификатор и материалы сделки, ЕПК клиента, финансовая отчётность и данные об обеспечении,
релевантный набор ВНД, история клиента и группы, внешние и отраслевые источники.

**Выход:**
Структурированный перечень рисков по типам с уровнем (severity), кратким обоснованием, ссылками на
источники, пометкой нехватки данных и предложенными мерами минимизации.

---

## Описание

Агент оценивает сделку/клиента и выводит риск-менеджеру структурированную картину рисков по типам.
Он не заменяет суждение: по каждому риску показывает **уровень, обоснование и источник**, честно
отмечает, где данных не хватает и почему итоговая оценка неполна, и предлагает меры минимизации —
работает как второй взгляд, а не как чёрный ящик или дубль методологии.

### Типы рисков (таксономия)

| Тип риска | Что оценивает |
|-----------|---------------|
| **Репутационный** | Угроза деловой репутации банка от связи с клиентом/сделкой: негативный публичный фон, сомнительные связи, санкционный/криминальный след. |
| **Правовой** | Юридические пороки сделки: оформление, оспоримость, судебные споры, несоответствие требованиям, дефекты обеспечения. |
| **Акционерный** | Риски структуры владения и бенефициаров: смена контроля, конфликт акционеров, номинальные/скрытые владельцы. |
| **Недостаточность обеспечения** | Залог/обеспечение не покрывает обязательства: низкая ликвидность, переоценка, недостаточный дисконт, обременения. |
| **Приостановление деятельности** | Риск остановки бизнеса клиента: отзыв лицензий, санкции, блокировки счетов, разрыв цепочек поставок. |
| **Диверсификация / концентрация** | Чрезмерная концентрация на контрагенте, отрасли, регионе или единственном источнике выручки. |
| **и др.** | Кредитный, рыночный, отраслевой; EWS-сигналы, проблемные контрагенты, исторический негатив. |

### Поведение (критические требования)

- Первичные/доверенные источники, **всегда со ссылкой** для перепроверки.
- **Явно** сообщает, каких данных не хватает и почему вывод по риску неполон; не «докручивает» оценку.
- По каждому риску — **уровень + обоснование + мера минимизации**, а не только ярлык.
- Второй взгляд для риск-менеджера, не автопилот.

## Сценарии использования

**S1. Скоринг рисков по новой сделке.**
Риск-менеджер запускает оценку → агент проходит все типы рисков, выводит перечень с уровнями и
обоснованием, подсвечивает критичные (напр. недостаточность обеспечения + акционерный).

**S2. Фокус на конкретный тип.**
Риск-менеджер спрашивает «оцени репутационный и правовой риск» → агент даёт разбор только по этим
типам со ссылками на источники и предложенными мерами.

**S3. Красный флаг с историей.**
При оценке агент поднимает исторический негатив (прошлый дефолт, банкротство связанного лица) и
относит его к соответствующему типу риска; если доступа к истории нет — пометка «не проверено».

**S4. Меры минимизации.**
По выявленным рискам агент предлагает меры (ковенанты, доп. обеспечение, лимиты концентрации),
опираясь на похожие прошлые сделки — как второе мнение, не готовое решение.
