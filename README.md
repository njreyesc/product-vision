# product-vision — комплект ТЗ на систему скиллов

Набор технических заданий на систему скиллов, моделирующую сквозную цепочку
**Product Vision → Бизнес-архитектура → ИТ-архитектура → Валидатор** с принципами
Spec-Driven Development (SDD): единый handoff-контракт, трассируемость, gate-проверка.

> Контекст-пример во всех документах — платформа оценки рисков (risk assessment).
> Это ТЗ: сами скиллы по ним не создаются.

## Единый контракт

Базовый handoff-контракт для всех артефактов:
`id` / `type` / `text` / `trace_up` / `source` / `status` / `owner` / `version`.

- `trace_up` — внутренняя трассировка к родительскому артефакту цепочки
  (`GOAL-*`, `PRIN-*`, `CAP-*`, `REQ-*`). Для верхнего уровня Vision допустимо
  значение `ROOT` или ссылка на будущий `CONST-*`.
- `source` — внешний источник/provenance: стратегия, документ, тикет, письмо,
  встреча, регуляторное требование.
- `covers` — расширение контракта только для ИТ-компонентов и mapping-записей:
  какие `CAP-*`/`REQ-*` закрывает компонент.
