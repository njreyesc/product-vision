## Step 0 — Core Review Flow

### 1. Premise Challenge — та ли это проблема
- **Правильная проблема?** Да. Не «хотят ли AI-анализ» (доказано поведением — обезличивание→ChatGPT),
  а «дать это **в периметре**, с ВНД и историей». Именно это оправдывает свой продукт.
- **Что если ничего не делать?** Клиент продолжает лить обезличенные данные в публичную модель —
  растущий комплаенс-риск у него, упущенный продукт у нас.
- **Реальный исход для пользователя:** аналитик получает заключение по сделке за минуты, не выпуская
  данные наружу, и не пропускает историчный красный флаг («за что увольняют»).

### 2. Existing Code Leverage
- Наработок продукта в репо нет (это ТЗ-репозиторий). Переиспользуем **методологию**: цепочка
  `product-vision → business-architecture → it-architecture → validator` и handoff-контракт (`id/trace_up`).
- Клин A и крючок C ложатся на `SCOPE-01` и `SCOPE-04` из vision — не изобретаем заново.

### 3. Dream State Mapping (трактория)
```
Сейчас            → Этот план (R0)         → Идеал 12 мес
обезлич.→ChatGPT    чат по сделке + короткое   полный «второй риск-мозг»:
ручные скрины       заключение (периметр)      ВНД-комплаенс, EWS, стресс CF,
ручной алгоритм     + историчность/EWS-хук      отрасль, сводки ритейлеров,
(утечка данных)     (A + C)                     контракты/вложения
```
Трактория здоровая: R0 = клин, не тупик — крючок C уже задаёт вектор к «мозгу».

### 4. Implementation Alternatives
Разобраны в office-hours (A / B / C). Выбран **A + C** (Selective Expansion). B = горизонт.

### 5. Mode-Specific Analysis — SELECTIVE EXPANSION
**Baseline (safe, входит в R0):**
- **A. Чат по одной сделке** на её документах → короткое заключение: кто/что/зачем пришёл,
  риски в обе стороны, плюсы/минусы, бенефициар. Полное рассуждение — по запросу (саммари→детали).
- Периметр: данные не покидают контур.

**Cherry-pick — принятый кандидат расширения:**
- **C. Историчность / EWS-подсветка** — при разборе сделки агент сам поднимает красный флаг из истории
  клиента/группы (кейсы: контрагент-банкрот; «кинул банк 5 лет назад»). Бьёт в «за что увольняют»,
  даёт вау-демо. **Принят стейкхолдером в R0.**

**Отклонённые кандидаты → `TODOS.md` (не выброшены, отложены):**
- ВНД-комплаенс и факторы нестандартности (узкий список ВНД) — R1.
- Анализ фин. отчётности: расшифровки, ОСВ, запасы, Excel; стресс CF-модели — R1/R2.

### 6. Temporal Interrogation — решения, которые нельзя отложить
Их придётся принять сейчас, иначе имплементер упрётся:
- **T-1 · Формат периметра** (self-hosted модель / приватный контур). Блокирует всё. → `Q-05`, в `it-architecture`.
- **T-2 · Доступ к истории клиента/группы** для крючка C. Без него C нереализуем. → `Q-02`.
- **T-3 · North Star: время vs доля принятых заключений** — влияет на то, что оптимизируем в R0. → `Q-03`.
- **T-4 · «Историчность» из каких источников** (внутренние базы vs ручной ввод) — определяет объём C.

### 7. Mode Selection
Зафиксировано стейкхолдером: **SELECTIVE EXPANSION**.

## Prime Directives — применение на vision-altitude

- **Zero silent failures:** заключение агента ВСЕГДА показывает, каких данных не хватило
  (нет доступа к истории → явная пометка «историчность не проверена»), а не молча пропускает.
- **Data flows have shadow paths:** для чата по сделке карта путей — ниже.
- **Observability = scope:** метрики North Star (доля принятых заключений, выгрузки в ChatGPT→0) —
  первоклассный deliverable, не «потом».
- **Deferred work written down:** см. `TODOS.md`.
- **Diagrams mandatory:**

```
Данные сделки ──▶ [Агент: чат по сделке] ──▶ Короткое заключение
(документы,          │  саммари→детали        (кто/что/зачем,
 в периметре)        │                         риски, бенефициар)
                     ▼
              [Крючок C: историчность/EWS]
                     │
        ┌────────────┼─────────────┐
        ▼            ▼              ▼
   есть история  нет доступа    флаг найден
   → красный     → пометка      → подсветить
     флаг          «не            в заключении
                   проверено»
```
Shadow paths: нет документов → отказ с причиной; нет доступа к истории → явная пометка (не тишина);
пустой результат по EWS → «сигналов не найдено», а не пропуск секции.
